# Reports Directory

This directory stores generated forensic PDF reports.

## Forensic Structure
Generated reports contain:
- Unique Report ID (`DS-XXXXXXXXXXXX`)
- UTC Timestamp
- Original file metadata & SHA-256 / MD5 cryptographic hashes
- Facial localization bounding boxes
- Frame-level video timeline breakdown (for videos)
- Visual Attention map overlays (for images)
- Technical observations and documented limitations
- Mandatory legal and forensic disclaimer
